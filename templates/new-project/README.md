# New Project Starter

This starter shows the minimum file set for a new repository adopting the Agent Collaboration Protocol.

## Suggested Layout

- `README.md`
- `.agent/protocol.md`
- `.agent/context.md`
- `.agent/next.md`
- `.agent/task.md`
- `.agent/review.md`
- `.agent/opencode-result.md`
- `.agent/decisions.md`
- `.agent/backlog.md`
- `.agent/project-adapter.md`

## First Steps

1. Fill in `.agent/project-adapter.md`.
2. Set `.agent/next.md` to the current phase and next action.
3. Create the first task only after the adapter is ready.
4. Keep all repository-specific facts in the adapter, not in the core protocol.
